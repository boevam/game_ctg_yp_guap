# Учебная практика. Создание игры с интерфейсом на языке программирования Python. 
Игра написана на языке программирования Python в рамках учебной практики в Санкт-Петербургском Государственном Университете Аэрокосмического Приборостроения (ГУАП) студентами группы 4526 1 курса направления 09.03.02 (Информационные системы и технологии) Боевой Марией и Полозовой Миланой. 

# CУТЬ ИГРЫ
Персонаж автоматически движется вперёд, а задача игрока — уклоняться от препятствий, перепрыгивать преграды или уничтожать их. Цель игры продержаться как можно дольше.

# УПРАВЛЕНИЕ
Управление основано на клавишах управления курсором и space.
